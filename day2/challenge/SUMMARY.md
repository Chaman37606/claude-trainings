# 🏥 Pharma Shipment Risk Analyzer - Complete Project Summary

## 📊 Project Overview

A production-ready pharmaceutical supply chain risk management tool built with creative Claude Code integration. Analyzes shipment data, identifies risks, and provides AI-powered recommendations.

## 🧮 Risk Scoring Algorithm

```python
Risk Score = (
    (Temperature Deviation × 0.40) +
    (Delivery Delay × 0.30) +
    (Incident Count × 0.20) +
    (Compliance Issues × 0.10)
) × 100

Risk Levels:
- 0-30: LOW (Green) ✅
- 31-60: MEDIUM (Yellow) ⚠️
- 61-85: HIGH (Orange) 🟠
- 86-100: CRITICAL (Red) 🔴
```

## 🚀 How to Run

### Quick Start (5 minutes)

```bash
# 1. Setup
cd challenge/pharma-shipment-analyzer
bash setup.sh

# 2. Terminal 1 - Backend
cd backend && python main.py

# 3. Terminal 2 - Frontend
cd frontend && npx http-server . -p 3000

# 4. Open browser
# http://localhost:3000
```

### API Endpoints

| Endpoint | Method | Purpose |
|----------|--------|---------|
| `/api/upload` | POST | Upload Excel file |
| `/api/stats/{file_id}` | GET | Dashboard metrics |
| `/api/risks/high/{file_id}` | GET | Top 5 high-risk |
| `/api/chart-data/{file_id}` | GET | Chart data |
| `/api/recommendations/{file_id}` | GET | AI insights |
| `/api/export/{file_id}` | GET | Export report |

## 📊 Sample Excel Format

Your file needs these columns:

```
shipment_id | origin | destination | temp_min | temp_max | temp_actual | status | delivery_date | handler_id | incidents | regulatory_flags
```

Example:
```
SHP-2024-001 | NYC | Boston | 2 | 8 | 27.5 | Delivered | 2024-01-15 | H001 | 1 | FDA Investigation
SHP-2024-002 | LA | SF | 2 | 8 | 5.2 | Delivered | 2024-01-14 | H002 | 0 | -
```
